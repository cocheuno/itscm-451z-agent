**Quirks.** The GBM artifact is 2.7 MB compressed (SVD 50 components); at 100 components it is 4.7 MB and
trips the "few MB" rule, which is why the lecture says 50. The LLM row's cost depends on the model in
`.env` (`claude-sonnet-4-6` default, $3 and $15 per million tokens); the price table in `llm_classify.py`

and the student must add a row. Structured output (`output_config.format`) is what makes the label set
enforced; if a model rejects it the API returns 400 with that field named.

**Measured.** TF-IDF+SVD50+HGB on August 0.994 / macro F1 0.990, fit 2.1 s; on the 40 holdout 1.0. Bake-off
on the instructor's machine (Oct 6, claude-sonnet-4-6): rules 0.15 / 33 unclassified; model:0.1 1.0 at 5 ms;
llm 0.625 accuracy, 0.665 macro F1, 1.3 s, $0.0012 per prediction, weakest class Software at 0.46.

**Corpus caveat.** The synthetic text is separable by a bag of words, so every local model scores 1.0 and
the bake-off differentiates on latency and cost only. The lectures say so and make the student explain
it. Hardening the corpus (a share of tickets drawn from a cross-category generic phrase bank) would put the
baseline near 0.85 and make the 0.80 threshold bite; it costs a regenerated corpus, a new manifest and a
20-minute PDI reload. Still your call.

purpose; the rule lives in the Module 12 output filter, and lecture 05b makes the student watch a real

**Answer key.**

```python
    def update_with_before_image(self, table: str, sys_id: str, payload: dict) -> tuple[dict, dict]:
        before = self.get(table, sys_id, list(payload))
        after = self.update(table, sys_id, payload)
        return before, after

def rollback(sn, before_image: dict, *, live: bool = False) -> dict:
    fields = before_image["fields"]
    if not live:
        return {"dry_run": True, "would_set": fields}
    sn.update(before_image["table"], before_image["sys_id"], fields)
    return {"dry_run": False, "set": fields}
```

not consumed by a failed attempt. `rollback` has no schema on purpose. Nothing creates `logs/` until the
first write.

**Answer key.**

```python
def expected_count(history, change_end, hours=WINDOW_HOURS, baseline_days=BASELINE_DAYS, category=None):
    start = change_end - pd.Timedelta(days=baseline_days)
    before = history[(history["opened_at"] >= start) & (history["opened_at"] < change_end)]
    if category is not None:
        before = before[before["category"] == category]
    per_hour = len(before) / (baseline_days * 24)
    return per_hour * hours
```
